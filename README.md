# SmartHire

SmartHire is a resume-to-job matching and career guidance
application built using classical Machine Learning.

## Core Features

1. Resume Category Classification
2. Content-Based Job Recommendation
3. Skill-Gap Analysis
4. Streamlit Web Application

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit
